# 🏐 VoleySapport

Telegram-бот, который отвечает на вопросы по правилам волейбола
(ФИВБ/ВФВ 2025–2028) через AI.

## ✨ Возможности

- Ответы на вопросы по правилам волейбола
- Ссылки на пункты правил
- Дневной лимит — 5 запросов в день
- Хранение юзеров в JSON
- Только команда `/start`

## 🛠 Стек

- Python 3.11
- pyTelegramBotAPI
- DeepSeek API
- JSON (хранение данных)

## 🚀 Запуск

```bash
pip install pyTelegramBotAPI requests
python main.py
```

## Настройка
Откройте config.py, после чего укажите в первом параметре токен телеграма, во втором токен от дипсика.
Если из России то используйте ggsel/playrok и другие, я лично через китайца пополнял.
